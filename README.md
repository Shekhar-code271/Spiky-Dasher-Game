# 🏃‍♂️ Spiky Dasher Game

A lightweight, fast-paced 2D platformer browser game built entirely with vanilla **HTML5**, **CSS3**, and **JavaScript**[cite: 1, 2, 3]. Jump, dash, navigate portals, and avoid deadly spikes as you race through multiple dynamic levels!

## ✨ Features

* **Pure Vanilla Tech Stack:** Built with zero external frameworks or libraries—just clean HTML, CSS, and modern JavaScript[cite: 1, 2, 3].
* **Dynamic Gameplay Mechanics:** Includes smooth gravity simulation, double-jumping, wall sliding, and a trailing particle effect.
* **Interactive Level Elements:** 
  * 🌋 Lava spikes and hazards[cite: 3]
  * 🌀 Working teleportation portals[cite: 3]
  * 🏁 Progressive level completion zones[cite: 3]
* **Gamepad & Keyboard Support:** Play seamlessly using your standard keyboard arrow keys or plug in a game controller (Gamepad API support).
* **Live Stats Tracker:** Real-time counters tracking your current death count and elapsed run time.
* **Procedural Theming:** Each level features randomised ambient colour themes.

## 🕹️ Controls

| Action | Keyboard | Gamepad |
| :--- | :--- | :--- |
| **Move Left / Right** | Left / Right Arrow Keys[cite: 1, 2] | D-Pad or Left Stick |
| **Jump / Double Jump** | Up Arrow Key[cite: 1, 2] | Face Buttons (A/B/X/Y) |
